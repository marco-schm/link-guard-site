Link Guard for Outlook

A pinned pane next to the message checks every link with the same checks as Link Guard for Thunderbird, and opens a link only after you approve its destination. It works in new Outlook, classic Outlook and Outlook on the web with Microsoft 365, Exchange and Outlook.com accounts.

The add-in is in development. Its documentation will appear here with the first release; until then, the source and setup instructions are on GitHub.
